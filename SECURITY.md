# Security Policy

## Reporting a vulnerability

Do not open public issues for security problems.

Report privately via GitHub [private vulnerability reporting](../../security/advisories/new)
or through [magenx.com/contact](https://www.magenx.com/contact). Include affected workflow or
component, impact, and reproduction steps.

Vulnerabilities in Magento / Adobe Commerce core go to the
[Adobe bug bounty program](https://hackerone.com/adobe).
